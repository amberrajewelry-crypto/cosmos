# Сайт бацзы — astropro.tech (топик «Сайт бацзы»)

Код страницы /bazi: Vite + TypeScript, `src/bazi/*`, `bazi.html`. Главная astropro.tech → /bazi.
Знания (книги, KB, мозг-эталоны): `~/projects/бацзы` (CLAUDE.md там — правила толкований).

## Как работать
1. `git pull --ff-only` (ветка `feature/bazi`; Mac работает через тот же GitHub).
2. Правка → `npx tsc --noEmit -p . && npx vitest run` → коммит на русском → `git push origin feature/bazi`.
3. Выкладка только по слову Владимира («выкатывай»):
   `nohup bash ~/projects/бацзы/tools/site-release.sh > ~/work/site-release.log 2>&1 &`,
   затем смотреть лог: `PROD:` = успех, `ОТКАТ:` — команда отката, `STOP/ВНИМАНИЕ` — разобраться.
4. Мобилку проверять на 375px (Playwright), горизонтального скролла быть не должно.
   Тестовая ссылка: `/bazi?d=1991-11-10&t=00:37&p=42.27,42.70,Asia/Tbilisi,Kutaisi&g=m`.

## Правила текста — «софт для людей»
- Простым языком: без иероглифов, процентов, ссылок на книги и авторов, без «ствол/ветвь/господин дня»
  в основных блоках (термины — только в свёрнутом «Подробном разборе»).
- Народные звёзды (神煞) не показывать, смерть не предсказывать.
- Без SEO-страниц, статей и английской версии. Метрика — позже, по команде.

## Нельзя
- Пушить в main, force push, коммитить `.env`/ключи, трогать `.vercel`.
- Откат прода — только `vercel promote <url>` из лога релиза и только по команде.
