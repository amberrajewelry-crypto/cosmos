# Голосовой расчёт натальной карты — спека (26.09.2026)

Запрос Владимира: «в натальную карту такой голосовой расчётник» (по мотивам «Джарвиса»).

## Что уже есть
- `src/ui/oracle.ts` — озвучка оракула (speechSynthesis, ru-голос, тумблер, по умолчанию выкл).
- `src/ui/birth-form.ts` — дата / время / город (локальная база `data/places`) → `moment()`.
- `src/natal/interp` — `reading()`: `message[]` («Послание карты»), `blocks`, `aspects`, `extras`.

## Что делаем (MVP, $0, без API и без LLM)
1. Кнопка микрофона у формы рождения (главная и /karta/). Подсказка: «Скажи: 15 марта 1990, 14:30, Тбилиси».
2. Распознавание — Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition`, `lang = ru-RU`).
3. Парсер фразы → `{date, time?, place?}`:
   - дата цифрами и словами («пятнадцатого марта девяностого года», «15.03.1990»);
   - время («в 14:30», «в полтретьего дня», «в 7 утра»);
   - город по падежу («в Тбилиси», «в Москве», «в Санкт-Петербурге») → поиск по стемам в базе мест.
4. Заполнение полей и показ того, что было распознано. Пропущенное (например, время) переспрашивается голосом один раз; при повторном пропуске строим без времени, как делает форма.
5. Строим карту → голосом читается «Послание карты» (`message[]`) через существующий `speak()`.
6. Голосовые вопросы после расчёта: «какой у меня асцендент», «что про Луну», «главный аспект», «хозяин карты». Ответ берётся по ключевым словам из готовых блоков `reading()`. Модели нет, число выдумать нельзя.

## Дополнение 26.09: лицо-собеседник («голова общается и отвечает»)
7. Разговор с лицом на главной: кнопка «Говорить с лицом», распознавание (п. 2), ответ — репликой лица
   (`oracle.say`) и голосом (`speak`). Режим «слушаю» подсвечивает лицо.
8. Ответы в два контура:
   - локальный: вопросы про карту/небо (асцендент, Луна, аспект, хозяин карты, «что над мной сейчас») —
     из `reading()` и `skyLines()`, мгновенно, без сети;
   - свободный: остальное — через существующий `ask()` (Puter gpt-4o-mini, $0 для нас, карантин чисел).
     Контекст = видимые Value + «Послание карты». Puter недоступен → честное «на это отвечу, когда
     подключат движок» + подсказка, что спросить локально.
9. Рот говорит: uniform `uTalk` в шейдере искр (`scene/particles.ts`), амплитуда от
   `SpeechSynthesisUtterance.onboundary` (слово → импульс, затухание ~120 мс). Смещаются только точки
   зоны рта (координаты — из body.bin, калибровка превью-скриптом). `prefers-reduced-motion` → без анимации.
10. Диалог держит последние 3 реплики как контекст для `ask()` («а что это значит?»).

## Честность / приватность
- Chrome отправляет звук в Google, Safari — в Apple. Писать рядом с кнопкой: «распознаёт браузер (Google/Apple); координаты и карта остаются у тебя».
- Firefox распознавание не поддерживает, поэтому там кнопку не показываем. Озвучка работает везде.

## Не делаем (YAGNI)
- ElevenLabs и платные голоса: деньги и ключ на сервере.
- LLM-собеседник: есть «Спросить», и он платный или ограниченный.
- «Интерфейс Железного человека»: визуал уже в тёмно-золотой теме.
