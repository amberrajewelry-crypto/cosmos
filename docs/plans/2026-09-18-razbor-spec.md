# Спека: «Разбор» — астрология + наука (18.09.2026)

Владимир: «мы делаем микс астрологии с наукой, а не отрицаем — везде делай разборы реально, чтобы характеризовал; загрузи книги по астрологии».

## Цель
К каждому расчёту по настоящему небу добавить настоящий астрологический разбор по классике,
с честной маркировкой: [ТОЧНО] — вычислено, [ТРАДИЦИЯ] — так трактует школа (источник указан), [НАУКА] — что об этом известно физике.

## Источники (docs/sources, public domain, archive.org)
- Птолемей «Тетрабиблос» (пер. Ashmand, 1822) — природы планет, знаков, аспектов.
- Уильям Лилли «Christian Astrology» (1647), т. 1–2 — значения домов, планет в знаках/домах, достоинства.
- Алан Лео «How to Judge a Nativity» (1903) — делинеации планет в знаках и домах, синтез карты.

## Что считаем
- Тропический знак каждого тела (традиция) + реальное созвездие (наука) — оба показываем.
- Дома — целознаковые от Асцендента (Птолемей/эллинистическая школа); без времени рождения домов нет — говорим честно.
- Аспекты: соединение, оппозиция, квадрат, тригон, секстиль между Солнце…Сатурн (орбисы 8/6/6/6/4°).

## Что пишем (src/natal/interp*.ts)
1. Природа 10 планет + 12 знаков (стихия, крест, управитель) — с источником.
2. Солнце, Луна, Асцендент в 12 знаках — полные разборы (характер, мотив, слабое место).
3. Меркурий, Венера, Марс, Юпитер, Сатурн в 12 знаках — разборы короче.
4. Уран, Нептун, Плутон — по знаку поколенческие: один текст + по дому.
5. Планеты в 12 домах (7 классических) — по Лилли/Лео.
6. Аспекты Солнце…Сатурн — по паре и типу (гармоничный/напряжённый/соединение).
7. Синтез: 3–5 фраз «ядро характера» из Солнце+Луна+ASC+самый точный аспект.

## Где показываем
- Оверлей карты (natal.ts): вкладка «Разбор» + лид досье переписан.
- /karta/: режим «Разбор» первым в списке.
- Страницы дат: блок «Солнце в знаке: что говорит традиция».
- Копи: везде «без толкований» → «по настоящему небу + разбор по классике, с пометкой, что проверяемо».

## Не делаем
Прогнозы «на неделю», совместимость по знаку без карт, генерацию текстов ИИ на лету.
